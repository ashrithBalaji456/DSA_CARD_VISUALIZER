Problem Statement

Medium / Gap Method
GFG • Merge Without Extra Space

Given two separate sorted integer arrays a[] of length m and b[] of length n, rearrange their elements without allocating any extra array so that a[] contains the smallest m elements in sorted order and b[] contains the remaining n elements in sorted order.

📌Key Constraints & How It Differs From LeetCode 88
  • • No Trailing Buffer: Unlike LeetCode 88, a[] has exact size m (no extra n empty slots at the end).
  • • O(1) Extra Space: You may not allocate a merged array of size m + n; elements must be swapped in-place across a[] and b[].
  • • Split Sorted Output: Together, printing a[] followed by b[] forms the complete sorted merged sequence.
Assumed Input Format
Line 1: m n (sizes)
Line 2: m sorted ints (a[])
Line 3: n sorted ints (b[])
Sample Output
Line 1 (a): 1 2 3 5
Line 2 (b): 8 9 10
From: 4 3 / 1 5 9 10 / 2 3 8

Algorithm Summary & Complexity Analysis

O((m+n) log(m+n)) • O(1) Space
🎯1. Why Use the Gap Method Instead of Insertion Shifting?

If you compare a[i] with b[0], swap, and re-insert into b[], worst-case time degrades to O(m × n). The Gap Method (inspired by Shell Sort) treats a[] and b[] as a single virtual array of length total = m + n and moves far-apart out-of-order elements across the boundary in large jumps first, reducing the time to O((m + n) log(m + n)) with strictly O(1) space!

⚙️2. How It Works Step-by-Step:
  • Ceiling-Half Gap (nextGap): Start at gap = ceil(total / 2) = (total / 2) + (total % 2). After each full pass, shrink gap by ceiling-half until gap == 1 runs, after which nextGap(1) returns 0 and stops.
  • Virtual Indexing (get & set): Any virtual index index < m maps to a[index]; any index >= m maps to b[index - m]—so the main loop never needs 3 messy if/else cases for (a,a), (a,b), and (b,b)!
  • Compare & Swap: Slide left = 0 and right = gap rightward until right == total. Whenever leftValue > rightValue, swap them in-place. Because both halves start sorted, the final gap = 1 pass guarantees the combined sequence is completely sorted.
TIME COMPLEXITY
O((m + n) log(m + n))
gap halves each outer pass (~log₂(m+n) passes), scanning at most m + n elements per pass.
AUXILIARY SPACE
O(1)
Purely in-place using only scalar integers (gap, left, right, leftValue, rightValue).
