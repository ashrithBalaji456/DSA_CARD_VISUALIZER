Problem Statement Medium
LeetCode 424

You are given a string s and an integer k. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most k times.

Return the length of the longest substring containing the same letter you can get after performing the above operations.

Example 1:
Input: s = "ABAB", k = 2 → Output: 4
Replace the two 'A's with two 'B's (or vice versa) to get "BBBB" of length 4.
Example 2:
Input: s = "AABABBA", k = 1 → Output: 4
Replace the middle 'A' with 'B' to form "AABBBBA", yielding "BBBB" of length 4.
Constraints: 1 ≤ s.length ≤ 105, s consists of only uppercase English letters, 0 ≤ k ≤ s.length.
Algorithm Summary & Sliding Window Invariant
O(1) Aux Space
Window Validity Formula: To make every character inside s[left .. right] match the most frequent character in that window, we keep all maxFreq occurrences of that dominant letter and replace the remaining characters:
replacementsNeeded = (right - left + 1) - maxFreq ≤ k
Why We Never Decrement maxFreq When Shrinking: Notice maxFreq is never recomputed downward when left++ runs. Since maxLength can only beat its previous best when (right - left + 1) grows larger, a new record requires a strictly higher maxFreq anyway — keeping the algorithm strictly Ο(N) instead of Ο(26 × N).
Time Complexity
Ο(N)

Single pass; right and left each advance at most N times.

Space Complexity
Ο(1)

Fixed 26-slot integer array int[26] for uppercase English letters.
