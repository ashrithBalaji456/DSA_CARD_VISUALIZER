Problem Statement Medium
LeetCode 155

Design a stack that supports push, pop, top, and retrieving the minimum element in constant Ο(1) time:
• MinStack() initializes the stack object.
• void push(int val) pushes the element val onto the stack.
• void pop() removes the element on the top of the stack.
• int top() gets the top element of the stack.
• int getMin() retrieves the minimum element in the stack.

Example 1:
Input: ["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
Output: [null,null,null,null,-3,null,0,-2]
Constraints: -231 ≤ val ≤ 231 - 1; pop, top, and getMin are always called on non-empty stacks; at most 3 × 104 calls.
Algorithm Summary & Dual-Stack Invariant
O(1) Time • O(N) Space
Prefix-Minimum Synchronization Invariant: Every depth level d in minStack stores the exact minimum of all elements from index 0 up to d in stack:
minStack[d] = Math.min(stack[d], minStack[d - 1])
Why Duplicate Minimums Are Pushed: Because minStack always has the exact same height as stack, popping the top element (stack.pop() and minStack.pop()) automatically restores the previous minimum in Ο(1) time without needing any comparison or branching during pop().
