Problem Statement Easy / DP
Infosys DSE 2025 • LeetCode 509 • GFG

Compute the Nth Fibonacci Number F(n) where F(0) = 0, F(1) = 1, and F(n) = F(n - 1) + F(n - 2) for n > 1.

DSE 2025 Variant Requirement: Implement the space-optimized Ο(n) time, Ο(1) space solution without declaring a temporary swap variable.
Also asked at: Accenture, TCS (alongside recursive & memoized complexity dry-runs).

Ex 1: n = 2 → 1 (0 + 1)
Ex 2: n = 3 → 2 (1 + 1)
Ex 3: n = 5 → 5 (0,1,1,2,3,5)
Ex 4: n = 6 → 8 (0,1,1,2,3,5,8)
Algorithm Summary & No-Temp Arithmetic Trick
O(N) Time • O(1) Space
How pair[0] & pair[1] Advance Without a Temp Variable: Before iteration i, let pair[0] = a = F(i - 2) and pair[1] = b = F(i - 1):
  1. pair[1] = pair[0] + pair[1]; ⇒ stores a + b = F(i) inside pair[1].
  2. pair[0] = pair[1] - pair[0]; ⇒ computes (a + b) - a = b = F(i - 1) and places it into pair[0].
Time Complexity
Ο(N)

Single linear loop from i = 2 to n (vs. Ο(2N) pure recursion).

Space Complexity
Ο(1)

Fixed 2-integer array int[2] (vs. Ο(N) DP table / recursion stack).
