class Solution {
  public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String str : strs) {
      char[] arr = str.toCharArray();
      Arrays.sort(arr);
      String key = new String(arr);
      map.putIfAbsent(key, new ArrayList<>());
      map.get(key).add(str);
    }
    return new ArrayList<>(map.values());
  }
}

49. Group Anagrams

Given an array of strings strs, group the anagrams together. You can return the answer in any order.

Example 1: strs = ["eat","tea","tan","ate","nat","bat"] → [["bat"],["nat","tan"],["ate","eat","tea"]]
Example 2: strs = [""] → [[""]]
Example 3: strs = ["a"] → [["a"]]
Constraints: 1 ≤ strs.length ≤ 104 • 0 ≤ strs[i].length ≤ 100 • strs[i] consists of lowercase English letters.
Algorithmic Mechanics (Sorted String Hash Key)

1. Canonical Signature: Any two anagrams produce the identical string once their characters are sorted alphabetically (e.g. "eat", "tea", and "ate" all become "aet").
2. HashMap Partitioning: Use this sorted string as the Map key: map.putIfAbsent(key, new ArrayList<>()), then append the original string.
3. Return Clusters: Extract new ArrayList<>(map.values()) containing all grouped sublists.

TIME COMPLEXITY O(N • K log K) N strings of max length K
O(N • K) SPACE COMPLEXITY Storage across all Map buckets
