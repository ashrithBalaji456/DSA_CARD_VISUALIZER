Problem Statement Easy
LeetCode 125

A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

Given a string s, return true if it is a palindrome, or false otherwise.

Example 1: Input: s = "A man, a plan, a canal: Panama" → Output: true
"amanaplanacanalpanama" reads identically forward and backward.
Example 2: Input: s = "race a car" → Output: false ("raceacar" is not a palindrome)
Example 3: Input: s = " " → Output: true (Empty string "" is a valid palindrome)
Constraints: 1 ≤ s.length ≤ 2 × 105, s consists only of printable ASCII characters.
Algorithm Summary & In-Place Optimization
O(1) Aux Space
On-The-Fly Alphanumeric Filtering: Rather than allocating a new cleaned string and reversing it (Ο(N) extra memory), two pointers (left and right) start at opposite ends and use inner while loops with Character.isLetterOrDigit() to skip punctuation and spaces in-place.
Guarding Inner Loops with left < right: Both inner skip loops check left < right before calling s.charAt(...) so strings containing exclusively punctuation or whitespace (such as " ") safely converge without throwing a StringIndexOutOfBoundsException.
Time Complexity
Ο(N)

Each index in s is visited at most once as left and right meet.

Space Complexity
Ο(1)

Zero string copies or auxiliary buffers; only two integer indices are stored.
