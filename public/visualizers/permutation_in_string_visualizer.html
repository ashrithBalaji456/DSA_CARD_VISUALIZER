Problem Statement Medium
LeetCode 567

Given two strings s1 and s2, return true if s2 contains a permutation of s1, or false otherwise.

In other words, return true if one of s1's permutations is a contiguous substring of s2.

Example 1:
Input: s1 = "ab", s2 = "eidbaooo" → Output: true
s2 contains one permutation of s1 ("ba" at indices [3..4]).
Example 2:
Input: s1 = "ab", s2 = "eidboaoo" → Output: false
Constraints: 1 ≤ s1.length, s2.length ≤ 104, s1 and s2 consist of lowercase English letters.
Algorithm Summary & Frequency Equivalence
O(1) Space
Frequency Signature Characterization: Generating all n! permutations of s1 is exponential. Instead, two strings of equal length n are permutations of each other if and only if they have identical character counts across all 26 lowercase letters (Arrays.equals(s1Freq, windowFreq)).
Constant-Time Window Slide (right = n .. m - 1): As the fixed-length window of size n shifts right by 1 position, only two frequency counts change: we increment windowFreq[s2.charAt(right) - 'a']++ and decrement windowFreq[s2.charAt(right - n) - 'a']--, then compare the 26-element arrays in Ο(26) = Ο(1) time.

Ο(N + M)

Ο(N) to initialize counts + Ο(26 × (M - N)) to slide across s2.
