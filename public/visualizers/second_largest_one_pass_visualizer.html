Problem Statement

Easy / Single-Pass Scan
GFG • Infosys DSE • Arrays

Given an integer array arr of size n, find and print the second-largest distinct element in the array using a single pass—without sorting the array.

📌Distinct-Value Rules & Edge Cases
  • • Strictly Distinct: Duplicates of the maximum do not count as second largest. For [5, 5, 4], the answer is 4, not 5.
  • • No Second Distinct Value: If the array has fewer than two distinct values (e.g., [5, 5], [42], or []), print -1.
  • • Negative Numbers Supported: Initializing with Integer.MIN_VALUE ensures arrays like [-3, -8, -1] work accurately (output -3).
Input Format (Assumed)
Line 1: n (number of elements)
Line 2: arr[0] arr[1] ... arr[n-1]
Output Format
Single integer: secondLargest
Prints -1 if none exists
Worked Examples
Ex 1: [12, 35, 1, 10, 34, 1] → 34 (Largest = 35, Second = 34)
Ex 2: [5, 5, 4] → 4 (Duplicate 5 ignored)
Ex 3: [5, 5] → -1 | Ex 4: [-3, -8, -1] → -3
🧠

Algorithm Summary & Complexity Analysis

O(n) Time • O(1) Space
🎯1. Why Track Top-2 in One Pass Instead of Sorting?

Sorting the array takes O(n log n) time and modifies the original order (and still needs an extra scan to skip duplicate maximums). Because we only care about the top 2 distinct values, maintaining just two scalar variables (largest and secondLargest) solves the problem in a single O(n) pass with zero extra memory!

⚙️2. How It Works Step-by-Step:
  • Case 1 (value > largest): A new champion arrives! First demote the old champion (secondLargest = largest), then crown the new one (largest = value). Reversing these two lines would overwrite the old champion!
  • Case 2 (value < largest && value > secondLargest): The value didn't beat Gold, is strictly distinct from Gold (value < largest), and beats Silver—so promote it directly into secondLargest.
  • Case 3 (Duplicate or Smaller): If value == largest or value <= secondLargest, skip it so duplicates never corrupt Silver.
  • Final Check: If secondLargest is still Integer.MIN_VALUE, no second distinct value existed—print -1; otherwise print secondLargest.
TIME COMPLEXITY
O(n)
Single enhanced for-loop visiting each element once with O(1) comparisons.
AUXILIARY SPACE
O(1)
Only two scalar registers (largest and secondLargest) beyond input.
