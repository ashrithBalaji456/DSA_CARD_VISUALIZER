class Solution {
  public boolean containsDuplicate(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int num : nums) {
      if (!set.add(num)) {
        return true;
      }
    }
    return false;
  }
}

Problem Statement & Architectural Summary

Easy • Solved
217. Contains Duplicate

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

Example 1: nums = [1, 2, 3, 1] → true (1 occurs at indices 0 & 3)
Example 2: nums = [1, 2, 3, 4] → false (All elements distinct)
Example 3: nums = [1,1,1,3,3,4,3,2,4,2] → true
Algorithmic Mechanics (Set Property)

Java's Set.add(e) method returns true if the element was successfully added, and false if it was already present. By testing !set.add(num), duplicate elements are identified immediately in a single pass without extra searches.

TIME COMPLEXITY O(n) Linear single pass
SPACE COMPLEXITY O(n) HashSet stores unique items
