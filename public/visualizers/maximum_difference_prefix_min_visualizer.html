Problem Statement

Easy / Prefix Minimum
LeetCode 121 • GFG Max Difference

Given an integer array arr of size n, find the maximum difference arr[j] - arr[i] such that the larger element appears strictly after the smaller element (i < j). This is the exact same core problem as Best Time to Buy and Sell Stock (One Transaction).

📌Rules, Edge Cases & Platform Convention
  • • Strict Order Constraint: You must choose an earlier index i and a later index j (0 ≤ i < j < n).
  • • No Positive Difference: If the array is non-increasing or has n < 2, this solution outputs 0 (matching LeetCode 121; note some GFG variants ask for -1).
  • • Order Matters: In [2, 3, 10, 6, 4, 8, 1], the minimum 1 at index 6 cannot pair with 10 at index 2 because 1 comes after 10.
Input Format
Line 1: n (array length)
Line 2: arr[0] arr[1] ... arr[n-1]
Output Format
Single integer: maxDifference
Returns 0 if n < 2 or no rise
Worked Examples
Ex 1: [2, 3, 10, 6, 4, 8, 1] → 8 (Smaller 2 @ idx 0, Larger 10 @ idx 2 → 10 - 2 = 8)
Ex 2: [7, 1, 5, 3, 6, 4] → 5 (Buy @ 1 [idx 1], Sell @ 6 [idx 4] → 6 - 1 = 5)
Ex 3: [9, 7, 5, 3, 1] → 0 (Strictly decreasing; no larger element after smaller)
🧠

Algorithm Summary & Complexity Analysis

O(n) Time • O(1) Space
🎯1. Why Use a Running Minimum Instead of Nested Loops?

A brute-force nested loop checks every pair (i, j) in O(n²) time. However, if you fix the later element arr[i], the only earlier element that can maximize arr[i] - arr[prev] is the smallest element seen before index i (minSoFar). Maintaining that single running minimum collapses the problem from O(n²) to a single O(n) scan!

⚙️2. How It Works Step-by-Step:
  • Guard (if (n < 2)): With 0 or 1 elements, no valid pair exists—print 0 and return safely before reading arr[0].
  • Initialize: Set minSoFar = arr[0] (smallest seen so far) and maxDifference = 0.
  • 1st — Compute Difference First: For each i = 1 .. n - 1, evaluate arr[i] - minSoFar and update maxDifference if larger. Checking before updating minSoFar guarantees the smaller element strictly precedes i.
  • 2nd — Update Running Floor: Set minSoFar = Math.min(minSoFar, arr[i]) so all future indices benefit if arr[i] is a new valley.
TIME COMPLEXITY
O(n)
Visits each element once from left to right performing two O(1) comparisons per element.
AUXILIARY SPACE
O(1)
Only scalar variables (minSoFar, maxDifference, i)—no auxiliary array.
