class Solution {
  public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) {
      return false;
    }
    Map<Character, Integer> map = new HashMap<>();
    // Count frequencies of s
    for (char ch : s.toCharArray()) {
      map.put(ch, map.getOrDefault(ch, 0) + 1);
    }
    // Check frequencies using t
    for (char ch : t.toCharArray()) {
      if (!map.containsKey(ch) || map.get(ch) == 0) {
        return false;
      }
      map.put(ch, map.get(ch) - 1);
    }
    return true;
  }
}

Problem Statement & Architectural Summary

Easy • Solved
242. Valid Anagram

Given two strings s and t, return true if t is an anagram of s, and false otherwise. An anagram is a word formed by rearranging the letters of another using all original letters exactly once.

Example 1: s = "anagram", t = "nagaram" → true
Example 2: s = "rat", t = "car" → false ('r' ≠ 'c')
Constraints: 1 ≤ s.length, t.length ≤ 5 × 104 • Lowercase English letters
Algorithmic Mechanics (Two-Pass Hash Counting)

1. Length Guard: If s.length() != t.length(), an anagram is impossible (false).
2. Build Frequency: Traverse s and increment counts in map.
3. Validate & Decrement: Traverse t. If a letter is missing or already has count $0$, return false; otherwise decrement its count by $1$.

TIME COMPLEXITY O(n) Two linear passes over length n
O(1) / O(k) SPACE COMPLEXITY ≤ 26 lowercase English keys
