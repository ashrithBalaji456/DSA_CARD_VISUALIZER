Problem Statement Hard
LeetCode 239

You are given an array of integers nums, there is a sliding window of size k which is moving from the very left of the array to the very right. You can only see the k numbers in the window. Each time the sliding window moves right by one position. Return the max sliding window.

Example 1: Input: nums = [1,3,-1,-3,5,3,6,7], k = 3 → Output: [3,3,5,5,6,7] 
Window position                Max
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
Example 2: Input: nums = [1], k = 1 → Output: [1]
Constraints: 1 ≤ nums.length ≤ 105, -104 ≤ nums[i] ≤ 104, 1 ≤ k ≤ nums.length.
Algorithm Summary & Monotonic Deque Invariant
Amortized O(N)
Four-Step Monotonic Decreasing Deque Rules:
  1. Expire Out-of-Bounds Front (pollFirst): If deque.peekFirst() ≤ i - k, that index has fallen behind the left edge of [i - k + 1 .. i].
  2. Prune Dominated Back (pollLast): Any earlier index j < i with nums[j] ≤ nums[i] can never become the maximum of any future window containing i.
  3. Push Candidate Index (offerLast(i)): Append i to preserve strictly decreasing values from front to back.
  4. Emit Window Maximum (peekFirst): Once i ≥ k - 1, the front index always holds the current window maximum in Ο(1).
Time Complexity
Ο(N)

Every index is pushed into deque once and popped at most once (2N operations total).

Space Complexity
Ο(k)

The deque stores at most k indices at any moment (excluding the n - k + 1 output array).
