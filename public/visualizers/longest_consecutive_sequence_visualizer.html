128. Longest Consecutive Sequence Medium
LeetCode

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence.

Important constraint: You must write an algorithm that runs in Ο(n) time.

Example 1:
Input: nums = [100, 4, 200, 1, 3, 2]
Output: 4 (sequence: [1, 2, 3, 4])
Example 2:
Input: nums = [0,3,7,2,5,8,4,6,0,1]
Output: 9 (sequence: [0, 1, 2, 3, 4, 5, 6, 7, 8])
Constraints: 0 ≤ nums.length ≤ 105, -109 ≤ nums[i] ≤ 109
Algorithm Architectural Summary
Optimal
Why Ο(n) and Not Ο(n log n)? Sorting the array takes Ο(n log n), violating the constraint. A HashSet allows Ο(1) average lookups.
The "Sequence Head" Trick: We only initiate a chain exploration if !set.contains(num - 1). This guarantees that elements in the middle of a streak are skipped in Ο(1). Every number is visited at most twice across the entire execution.
