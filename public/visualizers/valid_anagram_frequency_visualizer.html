Problem Statement Easy / Assessment
Infosys DSE

Two strings s1 and s2 are called anagrams if they contain exact same characters with the exact same frequencies, regardless of character order. Read two strings from standard input (one per line) and print "Yes" if they are anagrams, or "No" otherwise.

Ex 1: "listen", "silent" → Yes
Ex 2: "hello", "world" → No
Ex 3: "aabb", "bbaa" → Yes
Ex 4: "aab", "abb" → No
Ex 5: "abc", "abcd" → No (Different lengths caught immediately)
Algorithm Summary & Frequency Cancellation
O(N) Time • O(1) Space
Simultaneous +1 / −1 Balance Cancellation: Instead of sorting both strings (Ο(N log N)) or allocating two separate frequency maps, a single pass increments freq[s1.charAt(i)]++ and decrements freq[s2.charAt(i)]--. Every matching character contributes +1 and −1, cancelling cleanly back to 0.
Full UTF-16 Character Support (new int[65536]): Java's char type is an unsigned 16-bit UTF-16 code unit (0 .. 65535). Indexing directly into int[65536] supports lowercase letters, uppercase letters, digits, punctuation, and international Unicode characters with zero offset subtraction.
Time Complexity
Ο(N)

Single linear scan over N = s1.length() followed by a fixed constant scan.

Space Complexity
Ο(1)

Fixed-size int[65536] array independent of input string length N.
