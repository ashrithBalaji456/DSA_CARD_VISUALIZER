Problem Statement Medium
LeetCode 325

Given an integer array nums and an integer k, return the maximum length of a subarray whose elements sum to k.

A subarray is defined as a contiguous, non-empty sequence of elements within an array. If no such subarray exists, return 0.

Example 1:
Input: nums = [1, -1, 5, -2, 3], k = 3
Output: 4
• Subarray nums[0..3] = [1, -1, 5, -2] has sum = 3, length = 4.
Example 2:
Input: nums = [-2, -1, 2, 1], k = 1
Output: 2
• Subarray nums[1..2] = [-1, 2] has sum = 1, length = 2.
Constraints: 1 ≤ nums.length ≤ 2 × 105, -104 ≤ nums[i] ≤ 104, -109 ≤ k ≤ 109.
Algorithm Architectural Insights
Prefix Sum + Map
Mathematical Reduction: The sum of subarray nums[j+1..i] equals prefixSum[i] - prefixSum[j]. Setting this equal to k gives:
prefixSum[i] - k = prefixSum[j] = remaining
If remaining has appeared in our prefix sums before at index j, then the range from j + 1 to i has sum exactly k.
Why putIfAbsent (Greedy Preservation): To maximize subarray length length = i - j for a given current index i, we want j to be as small as possible (earliest occurrence). Using map.putIfAbsent(prefixSum, i) prevents later occurrences of identical prefix sums from overwriting earlier ones!
