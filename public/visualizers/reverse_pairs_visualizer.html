493. Reverse Pairs Hard
LeetCode

Given an integer array nums, return the number of reverse pairs in the array.

A reverse pair is defined as a pair (i, j) such that:
• 0 ≤ i < j < nums.length and
• nums[i] > 2 × nums[j]

Example 1:
Input: nums = [1, 3, 2, 3, 1]
Output: 2
• (1, 4) → nums[1]=3 > 2*nums[4]=2
• (3, 4) → nums[3]=3 > 2*nums[4]=2
Example 2:
Input: nums = [2, 4, 3, 5, 1]
Output: 3
• (1, 4) → 4 > 2*1
• (2, 4) → 3 > 2*1
• (3, 4) → 5 > 2*1
Constraints: 1 ≤ nums.length ≤ 5 × 104, -231 ≤ nums[i] ≤ 231 - 1.
Algorithm Architectural Insights
Divide & Conquer
Monotonic Pointer Advance in countPairs: Because both the left half [low..mid] and right half [mid+1..high] are already sorted recursively, as left increases, nums[left] is non-decreasing. Therefore, right never needs to reset back to mid + 1. This makes counting pairs strictly Ο(high - low) linear per merge step!
64-Bit Casting Guard ((long) nums[left] > 2L * nums[right]): If nums[right] ≥ 1,073,741,824 or ≤ -1,073,741,825, multiplying by 2 overflows standard 32-bit signed integers. Casting to long and multiplying with 2L prevents overflow bugs.
