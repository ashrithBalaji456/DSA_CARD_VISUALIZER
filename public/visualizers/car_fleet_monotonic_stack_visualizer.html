Problem Statement Medium
LeetCode 853

There are n cars at given miles away from the starting mile 0, traveling to reach the mile target. You are given two integer arrays position and speed, both of length n.

A car cannot pass another car, but it can catch up and then travel next to it at the speed of the slower car. A car fleet is a single car or a group of cars driving next to each other (speed = minimum speed in the fleet). If a car catches up to a fleet right at target, it is still considered part of that fleet. Return the number of car fleets that will arrive at the destination.

Example 1: Input: target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3] → Output: 3
[10,2] & [8,4] meet at 12; [0,1] travels alone; [5,1] & [3,3] meet at 6.
Example 2: target=10, [3], [3] → 1
Example 3: target=100, [0,2,4], [4,2,1] → 1
Constraints: 1 ≤ n ≤ 105, 0 < target ≤ 106, 0 ≤ position[i] < target (unique), 0 < speed[i] ≤ 106.
Algorithm Summary & Fleet Catch-Up Proof
O(N log N) Time • O(N) Space
Why Sort Cars Descending by Starting Position? Because cars cannot pass one another, a trailing car's behavior is determined strictly by the fleet immediately ahead of it. Sorting by position descending (Integer.compare(b[0], a[0])) lets us process cars from front to back.
Arrival-Time Comparison Rule (time > stack.peek()): Each car's unhindered arrival time is time = (double)(target - pos) / speed:
  • If time ≤ stack.peek(): The trailing car reaches target earlier or simultaneously, so it catches up and merges into the fleet ahead (no push).
  • If time > stack.peek(): It is too slow to catch the fleet ahead, so it forms a new independent fleet (stack.push(time)).
