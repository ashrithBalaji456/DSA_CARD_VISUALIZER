Problem Statement

Unified Left / Right
Arrays • Two Pointers • Reversal

Implement a single method rotate(int[] arr, int k, boolean right) that rotates an integer array either left (right = false) or right (right = true) by k positions in-place without duplicating the reversal logic.

  • • Normalize steps: k %= n
  • • If right == true: convert via k = n - k
  • • Execute left-rotation 3-step reversal: [0..k-1], [k..n-1], [0..n-1]
rotate([1,2,3,4,5], 2, false)
→ [3, 4, 5, 1, 2] (Left by 2)
rotate([1,2,3,4,5], 2, true)
→ [4, 5, 1, 2, 3] (Right by 2 = Left by 3)
🧠

Algorithm Summary & Complexity Analysis

O(N) Time • O(1) Space
✂Why Converting Right Rotation by k to Left Rotation by (n - k) Works:

On a circular array of length n, shifting every element right by k lands each element at the exact same index as shifting left by (n - k). After normalizing k %= n and applying if (right) k = n - k;, the exact same 3 left-rotation reversals handle both directions cleanly!

TIME COMPLEXITY
O(N)
Direction conversion is O(1); each element is swapped at most twice across the 3 reversals.
AUXILIARY SPACE
O(1)
In-place two-pointer swaps using only scalar variables (left, right, temp).
