Problem Statement Easy
LeetCode 20

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:
1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

Ex 1: s = "()" → true
Ex 2: s = "()[]{}" → true
Ex 3: s = "(]" → false
Ex 4: s = "([])" → true
Ex 5: s = "([)]" → false (Inner '[' must close before outer '(')
Constraints: 1 ≤ s.length ≤ 104, s consists of parentheses only '()[]{}'.
Algorithm Summary & LIFO Stack Invariant
O(N) Time • O(N) Space
Why a Last-In, First-Out (LIFO) Stack Is Ideal: In any nested expression such as "([])", the most recently opened bracket ('[') must always be the first one closed (']'). Pushing openers onto Stack<Character> places the innermost unclosed bracket directly at the top for Ο(1) stack.pop() verification.
Three Failure Conditions Caught by the Algorithm:
  • Orphan Closer (stack.isEmpty()): A closing bracket arrives with no preceding opener on the stack.
  • Type Mismatch (top != expected): The popped opener does not match the closing bracket family.
  • Unclosed Opener (!stack.isEmpty() at end): Scanning finishes with leftover opening brackets still sitting inside stack.
Time Complexity
Ο(N)

Single pass; each character is pushed and popped at most once in Ο(1).

Space Complexity
Ο(N)

Worst-case stack depth is N when all characters are opening brackets (e.g., "((([").
