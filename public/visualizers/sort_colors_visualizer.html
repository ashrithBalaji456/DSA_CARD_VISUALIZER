Problem Statement Medium
LeetCode 75

Given an array nums with n objects colored red, white, or blue, sort them in-place so that objects of the same color are adjacent, with the colors in the order red, white, and blue.

We will use the integers 0, 1, and 2 to represent the color red, white, and blue, respectively. You must solve this problem without using the library's sort function.

Example 1:
Input: nums = [2,0,2,1,1,0] → Output: [0,0,1,1,2,2]
Places all 0s first, then all 1s, then all 2s in-place.
Example 2:
Input: nums = [2,0,1] → Output: [0,1,2]
Constraints: n == nums.length, 1 ≤ n ≤ 300, nums[i] is either 0, 1, or 2.
Algorithm Summary & Loop Invariants
One-Pass O(1) Space
Four Partition Regions Maintained at Every Step:
  • [0 .. low - 1]: Confirmed 0s (Red)
  • [low .. mid - 1]: Confirmed 1s (White)
  • [mid .. high]: Unclassified window shrinking each iteration
  • [high + 1 .. n - 1]: Confirmed 2s (Blue)
Why Not Increment mid After Swapping with high? When nums[mid] == 2, swapping with nums[high] brings an uninspected element from the right into mid. We decrement high-- while keeping mid stationary so the next loop iteration inspects that newly arrived value.
