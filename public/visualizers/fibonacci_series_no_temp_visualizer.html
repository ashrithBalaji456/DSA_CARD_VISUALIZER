Problem Statement Easy / DP
Infosys DSE 2025 • LeetCode 509 • GFG

Generate and print the first n terms of the Fibonacci Series (F(0), F(1), ..., F(n - 1)), where F(0) = 0, F(1) = 1, and F(i) = F(i - 1) + F(i - 2).

DSE 2025 Variant Requirement: Compute and advance the Fibonacci sequence in Ο(n) time and Ο(1) auxiliary space without using a third temporary swap variable.
Related Variants: Fibonacci Number (Recursive + Complexity), Nth Fibonacci (DP) • Also asked at: Accenture, TCS.

Ex 1: n = 1 → "0"
Ex 2: n = 2 → "0 1"
Ex 3: n = 5 → "0 1 1 2 3"
Ex 4: n = 6 → "0 1 1 2 3 5"
Algorithm Summary & No-Temp Arithmetic Proof
O(N) Time • O(1) Space
Advancing (a, b) Without a Temporary Variable: At the start of iteration i, a = F(i) and b = F(i + 1):
  1. System.out.print(a); outputs F(i) (followed by " " if i < n - 1).
  2. b = a + b; stores F(i) + F(i + 1) = F(i + 2) inside b.
  3. a = b - a; computes (F(i) + F(i + 1)) - F(i) = F(i + 1) and places it into a.
Time Complexity
Ο(N)

Single linear loop of N iterations (vs. Ο(2N) pure recursion).

Space Complexity
Ο(1)

Only scalar variables (n, a, b, i) — zero arrays, DP tables, or recursion stack.
