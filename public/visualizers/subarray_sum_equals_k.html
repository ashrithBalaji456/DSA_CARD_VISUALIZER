Problem Statement Medium
LeetCode 560

Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.

A subarray is defined as a contiguous non-empty sequence of elements within an array.

Example 1:
Input: nums = [1, 1, 1], k = 2
Output: 2
• Subarrays [1, 1] at indices 0..1 and 1..2 each sum to 2.
Example 2:
Input: nums = [1, 2, 3], k = 3
Output: 2
• Subarrays [1, 2] at 0..1 and [3] at index 2 each sum to 3.
Constraints: 1 ≤ nums.length ≤ 2 × 104, -1000 ≤ nums[i] ≤ 1000, -107 ≤ k ≤ 107.
Algorithm Architectural Insights
Prefix Sum + Frequency Map
Mathematical Reduction: The sum of subarray nums[j..i] is prefixSum[i] - prefixSum[j - 1]. Setting this equal to k gives:
prefixSum[i] - k = prefixSum[j - 1] = remaining
Every previous occurrence of remaining in the prefix history represents a distinct valid starting point that forms a subarray ending at i summing to k.
Key Difference: LeetCode 325 vs LeetCode 560: • LC 325 (Max Length) stores the earliest index using putIfAbsent.
• LC 560 (Total Count) stores the frequency count of each prefix sum using getOrDefault(sum, 0) + 1, adding all occurrences to count.
