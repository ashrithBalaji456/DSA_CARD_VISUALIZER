229. Majority Element II Medium
LeetCode

Given an integer array of size n, find all elements that appear more than ⌊n / 3⌋ times.

Mathematical Fact: At most two distinct integers can each appear strictly more than ⌊n / 3⌋ times (since $3 \times (n/3 + 1) > n$).

Example 1:
Input: nums = [3, 2, 3]
Output: [3] (⌊3 / 3⌋ = 1, '3' appears 2 times > 1)
Example 2:
Input: nums = [1]
Output: [1] (⌊1 / 3⌋ = 0, '1' appears 1 time > 0)
Example 3:
Input: nums = [1, 2]
Output: [1, 2] (⌊2 / 3⌋ = 0, both appear 1 time > 0)
Constraints: 1 ≤ nums.length ≤ 5 × 104, -109 ≤ nums[i] ≤ 109.
Extended Boyer-Moore Principles
Linear & Constant Space
Triplet Cancellation Principle: When a number arrives that matches neither candidate1 nor candidate2, we cancel out one vote from candidate1, one from candidate2, and discard the third number. Any element appearing $> n/3$ times cannot be fully cancelled.
Why Pass 2 Verification is Mandatory: Unlike Majority Element I (where a majority element is guaranteed to exist), an array might have zero or only one element exceeding $\lfloor n / 3 \rfloor$. The candidates from Pass 1 are merely survivors, so Pass 2 counts their true frequency.
