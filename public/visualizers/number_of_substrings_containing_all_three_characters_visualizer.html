Problem Statement Medium
LeetCode 1358

Given a string s consisting only of characters a, b and c, return the number of substrings containing at least one occurrence of all these characters a, b and c.

Example 1: Input: s = "abcabc" → Output: 10
Valid substrings: "abc", "abca", "abcab", "abcabc", "bca", "bcab", "bcabc", "cab", "cabc", and "abc".
Example 2: Input: s = "aaacb" → Output: 3 ("aaacb", "aacb", and "acb")
Example 3: Input: s = "abc" → Output: 1 ("abc")
Constraints: 3 ≤ s.length ≤ 5 × 104, s only consists of 'a', 'b' or 'c' characters.
Algorithm Summary & Suffix Counting Proof
O(1) Aux Space
Why result += n - right; Counts All Valid Extensions in Ο(1): Suppose the current window s[left .. right] contains at least one 'a', 'b', and 'c'. Appending any remaining characters to its right (s[left..right], s[left..right+1], ..., s[left..n-1]) still preserves all three letters! There are exactly (n - 1) - right + 1 = n - right such valid ending positions for this left index.
Shrinking left++ Without Double Counting: Because we add n - right at the exact moment right reaches the earliest valid endpoint for left, and then immediately advance left++, every starting index left is counted at most once with zero duplicate substrings.
