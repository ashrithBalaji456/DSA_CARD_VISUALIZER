Problem Statement

Easy / Two Pointers
LeetCode 88 • In-Place Merge

You are given two non-decreasing sorted integer arrays nums1 (with m valid elements followed by n unused buffer slots) and nums2 (with n elements). Merge nums2 into nums1 in-place so that nums1 becomes a single sorted array of length m + n.

📌Related Problem Variants (Know the Difference!)
  • • LeetCode 88 (This Code): nums1 has size m + n with n trailing empty slots; merge everything directly into nums1.
  • • GFG Merge Without Extra Space: Two separate fixed-size arrays; rearrange so both arrays hold the combined sorted order without extra memory (gap / shell method).
  • • Extra-Array Merge: Allocate a new int[m + n] array and merge left-to-right (O(m + n) space, not in-place).
Assumed Input Format
Line 1: m n
Line 2: m sorted ints (nums1)
Line 3: n sorted ints (nums2)
Output Format
Space-separated merged nums1
Sample: 3 3 / 1 4 7 / 2 3 6
Output: 1 2 3 4 6 7

Algorithm Summary & Complexity Analysis

O(m + n) Time • O(1) Space
🎯1. Why Merge Backward From the End Instead of Forward?

If you merge forward from index 0, placing an element from nums2 into nums1 would overwrite unmerged elements in nums1 (forcing expensive O(m) shifts or an extra array). Because the n unused buffer slots sit at the back of nums1, filling from the right (k = m + n - 1 down to 0) guarantees the write pointer k never overtakes the read pointer i!

⚙️2. How the 3 Pointers (i, j, k) Work Step-by-Step:
  • Initialize at Ends: i = m - 1 (last valid in nums1), j = n - 1 (last in nums2), k = m + n - 1 (backmost write slot).
  • Pick the Larger Element: If i >= 0 && nums1[i] > nums2[j], lift nums1[i] into nums1[k] and do i--; otherwise lift nums2[j] into nums1[k] and do j--. Then decrement k--.
  • Why while (j >= 0) Is Enough: Once j < 0, every element of nums2 has been placed. Any remaining elements in nums1[0..i] are already in their final sorted positions!
TIME COMPLEXITY
O(m + n)
Each iteration decrements k and either i or j—at most m + n steps.
AUXILIARY SPACE
O(1)
In-place merge using only three integer pointers (i, j, k).
