Problem Statement

Left Rotation / In-Place
Arrays • Two Pointers • Reversal

Given an integer array arr of size N and a rotation count K, rotate the array to the left by K positions in-place by reusing the reverse() helper in three steps:

  • • Step 1: reverse(arr, 0, k - 1)  — Reverse the first k elements
  • • Step 2: reverse(arr, k, n - 1)  — Reverse the remaining n - k elements
  • • Step 3: reverse(arr, 0, n - 1)  — Reverse the entire array
Original: [1, 2, 3, 4, 5] (k = 2)
Step 1: [2, 1, 3, 4, 5]
Step 2: [2, 1, 5, 4, 3]
Step 3: [3, 4, 5, 1, 2]
🧠

Algorithm Summary & Complexity Analysis

O(N) Time • O(1) Space
✂How Left Rotation Reverses the Order of the 3 Reversals:

Split the array into prefix A (first k elements) and suffix B (remaining n - k elements). Reversing each half independently gives ARBR. Reversing the entire array then yields (ARBR)R = BA—moving the first k elements cleanly to the back without extra memory.

TIME COMPLEXITY
O(N)
Each element is swapped at most twice across the three reversal passes.
AUXILIARY SPACE
O(1)
Only scalar pointers left, right, and temp—no extra array.
