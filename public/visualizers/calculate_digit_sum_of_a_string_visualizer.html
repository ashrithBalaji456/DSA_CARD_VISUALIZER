Problem Statement Easy
LeetCode 2243

You are given a string s consisting of digits and an integer k. A round can be completed if s.length() > k. In each round:
1. Divide s into consecutive groups of size k (the last group may be smaller than k).
2. Replace each group with a string representing the sum of all its digits.
3. Merge consecutive groups together to form a new string and repeat while s.length() > k.

Example 1:
Input: s = "11111222223", k = 3 → Output: "135"
Round 1: "111"→3, "112"→4, "222"→6, "23"→5 ⇒ "3465". Round 2: "346"→13, "5"→5 ⇒ "135".
Example 2:
Input: s = "00000000", k = 3 → Output: "000"
Constraints: 1 ≤ s.length ≤ 100, 2 ≤ k ≤ 100, s consists of digits only.
Algorithm Summary & Complexity Analysis
Iterative Simulation
ASCII Digit Extraction & Safe Slicing: Instead of creating intermediate substrings with s.substring(), the inner loop bounds j < Math.min(i + k, s.length()) safely handle trailing partial groups while converting ASCII characters directly via s.charAt(j) - '0'.
Why Does the Loop Always Terminate? For k ≥ 2, a chunk of k digits has a maximum sum of 9k, whose string representation has at most ⌊log10(9k)⌋ + 1 < k digits for all k ≥ 2 (e.g., k=2 ⇒ max sum "18" reduces 3+ digits strictly downward). Thus, string length shrinks geometrically every round.
