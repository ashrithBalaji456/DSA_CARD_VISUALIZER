Problem Statement Medium
LeetCode 3

Given a string s, find the length of the longest substring without duplicate characters.
(A substring is a contiguous non-empty sequence of characters within a string.)

Example 1: Input: s = "abcabcbb" → Output: 3 ("abc" has length 3)
Example 2: Input: s = "bbbbb" → Output: 1 ("b" has length 1)
Example 3: Input: s = "pwwkew" → Output: 3 ("wke" is a substring; "pwke" is a subsequence)
Constraints: 0 ≤ s.length ≤ 5 × 104, s consists of English letters, digits, symbols and spaces.
Algorithm Summary & Sliding Window Invariant
Amortized O(N)
Uniqueness Invariant Maintained by HashSet<Character>: At the end of every outer for iteration, set contains exclusively the characters inside s[left .. right] with zero duplicates. Whenever s.charAt(right) is already in set, the inner while loop evicts s.charAt(left) and advances left++ until the duplicate is cleared.
Why Nested Loops Still Run in Linear Ο(N) Time: Although there is a while loop inside the for loop, left only moves forward from 0 to N - 1. Each character is added to set once and removed at most once (2N operations total).

Ο(N)
