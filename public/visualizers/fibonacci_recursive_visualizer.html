Problem Statement Easy / Recursion
LeetCode 509 • GFG • Infosys DSE

Write a recursive function to compute the Nth Fibonacci Number F(n) and analyze/dry-run its time and space complexity:
• F(0) = 0, F(1) = 1
• F(n) = F(n - 1) + F(n - 2) for n > 1.
Asked at: Infosys DSE, Accenture, TCS. (Note: DSE 2025 iterative variant computes Fibonacci without a temporary variable using b = a + b; a = b - a;.)

Ex 1: n = 2 → 1 (3 recursive calls)
Ex 2: n = 3 → 2 (5 recursive calls)
Ex 3: n = 4 → 3 (9 recursive calls)
Ex 4: n = 5 → 5 (15 recursive calls)
Algorithm Summary & Complexity Analysis
O(2ⁿ) Time • O(N) Space
Why Pure Recursion Has Exponential Ο(2n) Time: Each call fibonacci(n) spawns two recursive branches (n - 1 and n - 2), giving recurrence T(n) = T(n - 1) + T(n - 2) + Ο(1) ≈ Ο(φn) ≤ Ο(2n). Identical subtrees like fib(2) and fib(1) are recomputed repeatedly.
Time Complexity
Ο(2N)

Exact call count is 2 × F(n + 1) − 1 (reduced to Ο(N) with memoization).

Space Complexity
Ο(N)

Maximum depth of the JVM recursion call stack along the leftmost n → n-1 → ... → 1 path.
