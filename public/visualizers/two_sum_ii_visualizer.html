Problem Statement Medium
LeetCode 167

You are given a 1-indexed array of integers numbers that is already sorted in non-decreasing order. Find two numbers such that they add up to a specific target number, where 1 ≤ index1 < index2 ≤ numbers.length.

Return the indices of the two numbers index1 and index2 as an integer array [index1, index2] of length 2. Your solution must use only constant extra space.

Example 1: Input: numbers = [2,7,11,15], target = 9 → Output: [1, 2]
Example 2: Input: numbers = [2,3,4], target = 6 → Output: [1, 3]
Example 3: Input: numbers = [-1,0], target = -1 → Output: [1, 2]
Constraints: 2 ≤ numbers.length ≤ 3 × 104, -1000 ≤ numbers[i], target ≤ 1000, sorted in non-decreasing order.
Algorithm Summary & Monotonicity Proof
O(1) Space
Why Two Converging Pointers Work: Because numbers is sorted ascending, placing left = 0 (smallest value) and right = n - 1 (largest value) gives deterministic steering:
  • If sum < target: incrementing left++ is the only way to increase the sum.
  • If sum > target: decrementing right-- is the only way to decrease the sum.
0-Based vs. 1-Based Index Conversion: Java arrays are 0-indexed (0 .. n-1), whereas LeetCode 167 expects 1-indexed positions (1 .. n). Upon finding sum == target, we return new int[]{left + 1, right + 1}.
Time Complexity
Ο(N)

Each step eliminates one index; left and right meet in at most N - 1 steps.

Space Complexity
Ο(1)

Unlike HashMap Two Sum (Ο(N) space), only 3 scalar integers are allocated.
