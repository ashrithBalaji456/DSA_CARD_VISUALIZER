Problem Statement Medium
LeetCode 18

Given an array nums of n integers, return an array of all the unique quadruplets [nums[a], nums[b], nums[c], nums[d]] such that:
• 0 ≤ a, b, c, d < n
• a, b, c, and d are distinct.
• nums[a] + nums[b] + nums[c] + nums[d] == target
You may return the answer in any order.

Example 1:
Input: nums = [1,0,-1,0,-2,2], target = 0
Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
Example 2:
Input: nums = [2,2,2,2,2], target = 8 → Output: [[2,2,2,2]]
Constraints: 1 ≤ nums.length ≤ 200, -109 ≤ nums[i], target ≤ 109.
Algorithm Summary & Key Safeguards
Sort + 2-Sum Reduction
Reduction from 4Sum to Two Pointers: Sorting nums first (Ο(N log N)) enables two key optimizations:
  • Duplicate Pruning: Identical adjacent values for i, j, left, and right are skipped in Ο(1) without needing a HashSet.
  • Monotonic Search: Fixing (i, j) reduces the inner problem to sorted Two Sum on [j+1 .. n-1].
Preventing 32-Bit Signed Integer Overflow: Since each nums[k] can be up to ±109, adding four integers can reach ±4 × 109, overflowing Java's 32-bit int (±2.14 × 109). Casting (long) nums[i] + nums[j] + nums[left] + nums[right] ensures exact 64-bit arithmetic.
