Problem Statement Easy / DP
LeetCode 509 • GFG • Infosys DSE

Write a recursive function to compute the Nth Fibonacci Number F(n) and optimize overlapping subproblems using Top-Down Memoization (int[] dp):
• F(0) = 0, F(1) = 1
• F(n) = F(n - 1) + F(n - 2) for n > 1.
Asked at: Infosys DSE, Accenture, TCS. (Note: DSE 2025 iterative variant computes Fibonacci without a temporary variable using b = a + b; a = b - a;.)

Ex 1: n = 2 → 1 (1 + 0)
Ex 2: n = 3 → 2 (1 + 1)
Ex 3: n = 5 → 5 (0,1,1,2,3,5)
Ex 4: n = 6 → 8 (0,1,1,2,3,5,8)
Algorithm Summary & Complexity Analysis
O(2ⁿ) → O(N)
How if (dp[n] != -1) return dp[n]; Collapses Complexity: Without memoization, fib(n) recomputes the same subtrees exponentially many times (Ο(2n) calls). By caching each solved state in dp[n], every subproblem 2 .. n is computed at most once, reducing the entire recursion tree to 2n − 1 total calls (Ο(n)).
Time Complexity
Ο(N)

Each state dp[2..n] is solved once in Ο(1); subsequent lookups hit cache in Ο(1).

Space Complexity
Ο(N)

int[n + 1] memoization array + maximum recursion call stack depth of N.
