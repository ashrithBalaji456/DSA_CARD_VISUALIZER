Problem Statement

Medium / Two Pointers
LeetCode 31 • Next Permutation

Given an array of integers digits[] of length n, rearrange the elements in-place into the lexicographically next greater permutation. If the array is already in its highest possible (descending) order, wrap around to the lowest possible (ascending) order.

📌Dry-Run Walkthrough: [1, 2, 7, 4, 3, 1]
  • • 1. Pivot: i = 1 (val 2) because 2 < 7 (rightmost ascending pair).
  • • 2. Successor: j = 4 (val 3) — rightmost digit strictly > 2.
  • • 3. Swap: a[1] ↔ a[4] → [1, 3, 7, 4, 2, 1].
  • • 4. Reverse Suffix [2..5]: [1, 3, 1, 2, 4, 7].
Input Format
Line 1: n (number of digits)
Line 2: n space-separated ints
Sample Output
Input: 6 / 1 2 7 4 3 1
Output: 1 3 1 2 4 7

Algorithm Summary & Complexity Analysis

O(n) Time • O(1) Space
🎯1. Why Find the Rightmost Dip Instead of Generating All n! Permutations?

Generating and sorting all permutations takes factorial O(n! × n) time. To get the immediate next larger arrangement, we must keep as much of the left prefix unchanged as possible and make the smallest possible increase as far right as possible. A descending suffix (like [7, 4, 3, 1]) is already maximized—so the very first digit to its left that dips (a[i] < a[i+1]) is the exact pivot we must increment!

⚙️2. How the 5 In-Place Steps Guarantee the Exact Next Permutation:
  • 1–2. Locate Pivot (or Wrap): Scan right-to-left while a[i] >= a[i + 1]. If i < 0, the entire array is descending—reversing [0..n-1] wraps cleanly to the smallest permutation.
  • 3–4. Swap With Rightmost Successor: Because a[i+1..n-1] is strictly non-increasing, scanning from the right until a[j] > a[i] finds the smallest digit larger than the pivot. Swapping them keeps the suffix still in non-increasing order!
  • 5. Reverse the Suffix: Reversing the non-increasing suffix a[i+1..n-1] sorts it into ascending order in O(n)—giving the smallest possible tail after our newly incremented pivot.
TIME COMPLEXITY
O(n)
At most one right-to-left pivot scan, one successor scan, and one linear suffix reversal.
AUXILIARY SPACE
O(1)
Purely in-place using only scalar indices (i, j, left, right, temp).
