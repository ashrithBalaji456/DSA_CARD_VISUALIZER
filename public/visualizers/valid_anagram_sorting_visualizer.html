Problem Statement Easy • Strings
Infosys DSE • LeetCode 242 • GFG • HackerRank

Given two strings s1 and s2, check whether they are anagrams of each other. Two strings are anagrams if they contain the exact same characters with the exact same frequencies, rearranged in any order.
Also reported as: Anagram Check, Valid Anagram • Asked at: Infosys DSE (2021, 2024, 2025, 2026), Accenture, TCS, Wipro.

Ex 1: "anagram", "nagaram" → Yes
Ex 2: "rat", "car" → No
Ex 3: "listen", "silent" → Yes
Ex 4: "abc", "abcd" → No
Algorithm Summary & Canonical Sorting Proof
O(N log N) Time • O(N) Space
Canonical Form via Arrays.sort(): Every anagram family shares a unique sorted canonical sequence. After verifying s1.length() == s2.length() in Ο(1), converting both strings to mutable character arrays (toCharArray()) and sorting them in ascending UTF-16 order (Arrays.sort(a), Arrays.sort(b)) allows Arrays.equals(a, b) to verify exact multiset equality in a single pass.
Time Complexity
Ο(N log N)

Dual-Pivot Quicksort on char[] a and char[] b of length N (vs. Ο(N) frequency counting).

Space Complexity
Ο(N)

Allocates two char[] arrays of length N (2N bytes) because Java String objects are immutable.
