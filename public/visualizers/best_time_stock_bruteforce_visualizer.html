Problem Statement

Easy / Arrays
LeetCode 121 • One Transaction

Given an array prices where prices[i] is the price of a stock on day i, choose a single day to buy one stock and a different later day to sell it to maximize your profit (prices[sell] - prices[buy]).

  • • Constraint: You must buy before you sell (buy < sell).
  • • If prices only fall (no profit possible), return 0.
Ex 1: [7, 1, 5, 3, 6, 4]
→ Buy at 1, Sell at 6 → Profit 5
Ex 2: [7, 6, 4, 3, 1]
→ Only falling → Profit 0
🧠

Algorithm Summary & Complexity Analysis

Brute Force O(n²)
✂Exhaustive Pair Scan & Why It Takes O(n²):

The outer loop picks every possible buy day (0 .. n-1), and the inner loop tests every later sell day (buy + 1 .. n-1), updating maxProfit across all n(n - 1) / 2 pairs. (Optimal follow-up: tracking the running minimum price solves this in a single O(n) pass!)

TIME COMPLEXITY
O(n²)
Nested loops evaluate all n(n - 1) / 2 valid (buy, sell) pairs.
AUXILIARY SPACE
O(1)
Uses only scalar variables (buy, sell, maxProfit) beyond the input array.
