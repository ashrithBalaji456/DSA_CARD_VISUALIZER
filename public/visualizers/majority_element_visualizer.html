169. Majority Element Easy
LeetCode

Given an array nums of size n, return the majority element.

The majority element is defined as the element that appears more than ⌊n / 2⌋ times. You may assume that the majority element always exists in the array.

Example 1:
Input: nums = [3, 2, 3]
Output: 3 (⌊3 / 2⌋ = 1, '3' appears 2 times > 1)
Example 2:
Input: nums = [2, 2, 1, 1, 1, 2, 2]
Output: 2 (⌊7 / 2⌋ = 3, '2' appears 4 times > 3)
Constraints: 1 ≤ n ≤ 5 × 104, -109 ≤ nums[i] ≤ 109. The input guarantees a majority element exists.
Boyer-Moore Voting Theory
Linear &Constant Extra Space
Mutual Annihilation Principle: If every instance of a non-majority element is paired up and cancelled out with one instance of the majority element, the majority element is guaranteed to remain because it appears more than ⌊n / 2⌋ times.
Why count == 0 Resets Candidate: When count == 0, the current prefix of elements has had all candidate votes cancelled out equally. Discarding this balanced prefix leaves the majority element unchanged in the remaining suffix.
