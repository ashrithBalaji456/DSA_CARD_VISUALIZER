Problem Statement Medium
LeetCode 31

A permutation of an array of integers is an arrangement of its members into a sequence or linear order. The next permutation of an array of integers is the next lexicographically greater permutation of its integer.

If such an arrangement is not possible (i.e., the array is sorted in descending order), the array must be rearranged as the lowest possible order (sorted in ascending order). The replacement must be in-place and use only constant extra memory.

Example 1: Input: nums = [1,2,3] → Output: [1,3,2]
Example 2: Input: nums = [3,2,1] → Output: [1,2,3]
Example 3: Input: nums = [1,1,5] → Output: [1,5,1]
Constraints: 1 ≤ nums.length ≤ 100, 0 ≤ nums[i] ≤ 100.
Algorithm Summary & 3-Step Logic
O(1) Aux Space
Three-Phase In-Place Construction:
  1. Find Break Point (i): Scan right-to-left for the first drop nums[i] < nums[i + 1]. Everything to the right ([i+1..n-1]) is already maximized in descending order.
  2. Swap Next Greater (j): If i ≥ 0, find the rightmost element nums[j] > nums[i] and swap them to make the smallest possible increase at index i.
  3. Reverse Suffix ([i+1..n-1]): Because the suffix remains non-increasing after swapping, reversing it sorts it ascending in Ο(n) time.
Time Complexity
Ο(N)

At most two linear right-to-left scans and one suffix reversal.

Space Complexity
Ο(1)

Modifies nums directly in-place using scalar pointers and temp.
