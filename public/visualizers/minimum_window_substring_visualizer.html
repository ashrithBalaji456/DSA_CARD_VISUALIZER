Problem Statement Hard
LeetCode 76

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

Example 1: Input: s = "ADOBECODEBANC", t = "ABC" → Output: "BANC"
The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.
Example 2: Input: s = "a", t = "a" → Output: "a" (Entire string s is the minimum window)
Example 3: Input: s = "a", t = "aa" → Output: "" (Both 'a's from t must be included)
Constraints: 1 ≤ m, n ≤ 105, s and t consist of uppercase and lowercase English letters.
Algorithm Summary & Expand/Shrink Mechanics
O(m + n) Time
Two-Phase Dynamic Sliding Window:
  • Expand (right++): Absorb s.charAt(right) via need[ch]--. If need[ch] ≥ 0 after decrementing, it satisfied a required copy of t, so formed++.
  • Shrink (left++): Once formed == required, contract from left to minimize window length, releasing surplus copies (need[leftChar] ≤ 0) until a critical character (need[leftChar] > 0) exits.
Deficit vs. Surplus Sign Convention in need[128]: Positive entries (need[c] > 0) indicate copies still missing from the window; 0 means exact fulfillment; negative entries (need[c] < 0) record extra surplus copies buffered inside [left..right].
Time Complexity
Ο(M + N)

Ο(N) to count t + Ο(2M) as right and left traverse s once each.
