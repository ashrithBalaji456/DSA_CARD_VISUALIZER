Problem Statement Medium
LeetCode 15

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice: The solution set must not contain duplicate triplets.

Example 1:
Input: nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
Example 2:
Input: [0, 1, 1]
Output: []
Example 3:
Input: [0, 0, 0]
Output: [[0, 0, 0]]
Constraints: 3 ≤ nums.length ≤ 3000, -105 ≤ nums[i] ≤ 105.
Algorithm Summary & Insights
Sorting + Converging Two Pointers
Why Sort First (Arrays.sort(nums))? Sorting places negative values on the left and positive values on the right. Fixing anchor nums[i] reduces the remaining search to a linear two-pointer scan where sum < 0 cleanly dictates left++ (increase sum) and sum > 0 dictates right-- (decrease sum).
Three-Level Duplicate Elimination: 1. Anchor Guard: if (i > 0 && nums[i] == nums[i - 1]) continue;
2. Left Guard: After finding a valid triplet, advance left++ past identical neighbors.
3. Right Guard: Retreat right-- past identical neighbors.
