Problem Statement Medium
Rotate Array • LeetCode 189

Given an integer array arr and a non-negative integer k, rotate the array to the right by k steps, so that every element at index i moves to index (i + k) % n.
Approach 1 (Extra Array): Store the rotated elements in an auxiliary array temp[n], then copy them back into arr.

Example 1: Input: arr = [1, 2, 3, 4, 5, 6, 7], k = 3 → Output: [5, 6, 7, 1, 2, 3, 4]
The last 3 elements [5, 6, 7] wrap around to the front, followed by [1, 2, 3, 4].
Example 2: Input: arr = [-1, -100, 3, 99], k = 2 → Output: [3, 99, -1, -100]
Algorithm Summary & Complexity Comparison
O(N) Time • O(N) Space
Modular Cyclic Index Mapping (i + k) % n: First, k = k % n eliminates full-cycle rotations (since rotating an n-element array by n leaves it unchanged). Then, Pass 1 places each arr[i] directly into its rotated slot temp[(i + k) % n], and Pass 2 copies temp[i] back into arr[i].
Time Complexity
Ο(N)

Two linear passes of N steps each (2N = Ο(N)).

Space Complexity
Ο(N)

Allocates int[] temp = new int[n] (the 3-step reversal algorithm achieves Ο(1) space).
